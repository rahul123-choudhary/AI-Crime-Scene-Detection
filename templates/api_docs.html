POST /api/v1/detect · Analyze photograph payload

Accepts a multipart/form-data upload containing an image, runs inference through the requested model(s), saves crops, and returns detected evidence items with bounding box coordinates and threat severity.

Payload Parameters

  • image (File, Required): JPG, PNG, or WEBP binary data.
  • model (String, Optional): ensemble (default), weapon, or forensic.
  • confidence (Float, Optional): Threshold between 0.10 and 0.90 (default: 0.25).

cURL Example

curl -X POST http://127.0.0.1:5000/api/v1/detect \
  -F "image=@crime.jpg" \
  -F "model=ensemble" \
  -F "confidence=0.25"
GET /api/v1/cases · List indexed forensic cases

Query all archived crime scene investigations with optional text search and threat filter.

Query Parameters

  • q (String, Optional): Search keyword for title, location, or investigator.
  • threat (String, Optional): CRITICAL, HIGH, MEDIUM, or LOW.
  • limit (Integer, Optional): Default 20.
